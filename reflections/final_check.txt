What a pull request asks teammates to do:
A pull request formally asks your teammates to review, comment on, and approve the code changes you have made before they are integrated into the project's primary codebase.

Why branches and pull requests are used together:
Branches provide the isolated sandbox where you can build features safely, while pull requests serve as the gatekeeper mechanism to review that isolated work before it enters production.
