Problem:
Search a list of names for one target name and report whether it was found.

Input:
- a list of names
- one target name

Output:
- "Found" or "Not found"
- or an error if the list is empty

Pseudocode:
START
IF the list is empty
    THEN output "Error: list is empty"
ELSE
    SET found = false
    FOR each name in the list
        IF name equals target
            THEN found = true
            BREAK
        END IF
    END FOR

    IF found is true
        THEN output "Found"
    ELSE
        output "Not found"
    END IF
END IF
END
